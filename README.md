# README

Бывает так, что в процессе работы за компьютером вы начинаете что-то печатать и замечаете, что не переключили
раскладку на клавиатуре, а написанный текст уже довольно длинный (несколько слов или даже пара предложений),
в такие моменты бывает довольно неприятно стирать написанное и перепечатывать все с правильной раскладкой.

Представляю вам простую консольную утилиту для автоматической трансляции текста с одной раскладки на другую.

На данный момент поддерживаются 2 раскладки: английская и русская. По умолчанию трансляция осуществляется с 
английской раскладки на русскую. Исходный текст подается в stdin утилиты, результат выводится в stdout.

# Конфигурация

Утилита поддерживает гибкую конфигурацию. Например можно поменять местами транслируемые раскладки:
транслировать с русской раскладки на английскую. Для этого нужно составить простой yaml конфиг и подать его
как дополнительный аргумент программы. Структуру конфига см в lswitch.example.yaml
```
direction: "ru2en"
custom_map:
        "@": "#"
```

Поле custom_map задает специальные пользрвательские трансляции: если вам необходимо транслировать 2
конкретных символа.

# Сборка и примеры использования

Build the project
```
make build
```

Run tests
```
make test
```

Example of using (en2ru)
```
echo "Vbcnthhj,jn" | ./bin/lswitch
```

Example of using (ru2en). Firstly create a lswitch.yaml with the content that was descripted above.
```
echo "мшь сщташпюече" | ./bin/lswitch -config ./configs/ru2en.example.yaml
```
