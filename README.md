
# 💻 Обзор проекта

Добро пожаловать в мир комфортной работы с текстом! Представляем вашему вниманию удобную консольную утилиту lswitch, которая автоматически транслитерирует введенный вами текст с неправильной раскладкой клавиатуры. Больше никаких неприятных моментов, когда случайно забываешь сменить раскладку и печатаешь длинное предложение неправильно.

# ✨ Чем полезна эта утилита?

- Быстро исправляет случайные ошибки ввода.
- Экономит ваше время на повторное переписывание длинных фрагментов текста.
- Легко интегрируется в рабочий процесс через стандартный ввод-вывод (stdin → stdout).

# 🦸 Как работает?
Вы можете столкнуться с ситуацией, когда набираете текст, используя одну раскладку, думая, что активирована другая. Например, вы хотели набрать русские буквы, но компьютер воспринял ваши нажатия как английские символы. Утилита мгновенно преобразует ваш неверно набранный текст в правильный формат, избавляя вас от лишней работы.

# 📋 Основные возможности 🚀
- ~~Автоматическое определение направления перевода (русская ↔ английская раскладка).~~
- Гибкая настройка поведения утилиты через YAML-конфигурационные файлы.
- Специальные правила кастомизации символов (custom_map), позволяющие настроить индивидуальное поведение преобразования отдельных знаков.
- Быстрая интеграция в пайпы Unix-подобных ОС благодаря стандартному выводу результатов (stdout).

## 🧰 Флаги CLI

```
./lswitch [-config path] [-version] [-help] [-clipboard] [-quiet]
```
- `-config`: путь к YAML-конфигу.
- `-version`: показать версию и выйти.
- `-help`: показать справку по флагам и выйти.
- `-clipboard`: читать из буфера обмена и записывать результат обратно.
- `-quiet`: подавить вывод в stdout в режиме `-clipboard`.

# 🔥 Настройка и использование
Стандартная работа (английский → русский):
```
echo "Yfcrf hfcrwf" | ./bin/lswitch
```
Результат: выводит правильное слово на русском языке ("Привет друг").

Перевод с русского на английский (нужно задать направление через конфиг):
Для ручного изменения направления раскладки создайте файл конфигурации (например, lswitch.yaml) с таким содержанием:
```
direction: "ru2en"
custom_map:
        "@": "#"
```

Затем выполните команду с указанием пути к конфиг-файлу:

```
echo "Дрдг бютвш" | ./bin/lswitch -config configs/ru2en.example.yaml
```
Результатом будет верный английский вариант исходного текста.

### 🔎 Где ищется конфигурация
Конфигурация ищется в следующем порядке при отсутствии `-config`:
1. Переменная окружения `LSWITCH_CONFIG` (если задана)
2. Локальный файл `./lswitch.yaml`
3. `XDG_CONFIG_HOME/lswitch/lswitch.yaml`
4. `~/.config/lswitch/lswitch.yaml`
5. Исторический вариант: `~/.lswitch.yaml`

При наличии ошибок в найденном конфиге утилита завершится с сообщением об ошибке.

## 📦 Пререквизиты для сборки и использования
Перед сборкой и использованием убедитесь, что установлены:

- Go ≥ 1.25.0
- make (для целей из `Makefile`)
- git (для получения зависимостей)
- Внешние инструменты для работы с буфером обмена (один из): `xclip`, `xsel` или `wl-clipboard` — библиотека `github.com/atotto/clipboard` использует доступный в системе бэкенд
- Для сценария автокопирования/вставки: `xdotool` (X11). На Wayland функциональность `xdotool` ограничена; при необходимости используйте сессию «Ubuntu on Xorg» или альтернативы

Зависимости Go (подтягиваются автоматически через `go mod`):
- `github.com/atotto/clipboard v0.1.4`
- `gopkg.in/yaml.v3 v3.0.1`

Сборка вручную без Makefile:
```
go build -o bin/lswitch ./cmd/lswitch
```

## 🛠️ Установка утилиты `lswitch`
### Вариант A: через Makefile в `GOPATH/bin`
```
make install
```
Команда установит бинарь в `$(go env GOPATH)/bin` с учётом версии (через `-ldflags`), чтобы команда `lswitch` была доступна из терминала, убедитесь, что путь добавлен в `PATH`.

Проверить GOPATH и обновить PATH:
```
go env GOPATH
echo 'export PATH="$PATH:$(go env GOPATH)/bin"' >> ~/.bashrc
source ~/.bashrc
```
Для zsh используйте `~/.zshrc`.

Проверка установки:
```
which lswitch
lswitch -version
```

### Вариант B: системная установка в `/usr/local/bin`
После сборки:
```
make build
sudo install -m 0755 bin/lswitch /usr/local/bin/lswitch
```
Теперь `lswitch` доступен глобально: `lswitch -version`.

### ⌨️ Быстрая замена по горячей клавише
Вы можете назначить глобальное сочетание клавиш в вашей DE/WM, которое будет выполнять преобразование выделенного текста через буфер обмена:

1. Создайте шорткат, который запускает команду:
   ```
   lswitch -clipboard -quiet
   ```
2. Поведение:
   - Программа прочитает текущий текст в буфере обмена, преобразует его и запишет обратно.
   - Если хотите видеть результат в терминале/нотификации — уберите `-quiet`.
3. Советы:
   - Для Wayland/X11 убедитесь, что установлен доступ к системному клипборду. Библиотека `github.com/atotto/clipboard` использует доступные системные механизмы (xclip/xsel/wl-clipboard), при необходимости установите их.

## 🖱️ Автокопирование → перевод → вставка (скрипт `scripts/run.sh`)
Этот скрипт автоматизирует цикл: скопировать выделение → преобразовать через `lswitch` → вставить результат обратно в активное окно. Внутри используется `xdotool` для отправки сочетаний клавиш.

### Установка скрипта в систему
Рекомендуемое место: `/usr/local/bin`.

1) Сделать исполняемым и установить системно под удобным именем (например, `lswitch-run`):
```
sudo install -m 0755 scripts/run.sh /usr/local/bin/lswitch-run
```

2) Убедиться, что бинарь `lswitch` доступен из PATH. Если вы запускаете бинарь из `bin/lswitch`, отредактируйте строку запуска внутри скрипта под ваш путь. В `scripts/run.sh` это строка, где вызывается утилита:
```
../bin/lswitch -clipboard -quiet
```
Замените её на один из вариантов:
- Если `lswitch` в PATH: `lswitch -clipboard -quiet`
- Если фиксированный путь: `/absolute/path/to/lswitch -clipboard -quiet`

3) Проверьте, что установлен `xdotool`:
```
sudo apt update && sudo apt install -y xdotool
```

Примечания:
- `xdotool` работает в X11. В Wayland (по умолчанию в Ubuntu 24.04) его возможности ограничены. Для корректной работы выберите сессию «Ubuntu on Xorg» на экране входа, либо рассмотрите альтернативы (например, `ydotool`).
- Параметр `-quiet` подавляет вывод в терминал, чтобы скрипт работал «тихо» при запуске через хоткей.

### Создание пользовательской комбинации клавиш в Ubuntu 24.04
1) Откройте «Настройки» → «Клавиатура» → «Комбинации клавиш» (Keyboard → Keyboard Shortcuts)
2) Пролистайте вниз и нажмите «Добавить ярлык…» (Add Shortcut)
3) Заполните поля:
   - Имя: «lswitch: преобразовать выделение» (любое удобное)
   - Команда: `/usr/local/bin/lswitch-run`
4) Нажмите «Добавить», затем кликните по новому ярлыку и задайте желаемое сочетание (например, Ctrl+Alt+L)
5) Проверьте работу: выделите текст в любом приложении, нажмите хоткей — текст будет заменён преобразованным вариантом
