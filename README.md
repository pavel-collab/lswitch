
# 💻 Обзор проекта

Добро пожаловать в мир комфортной работы с текстом! Представляем вашему вниманию удобную консольную утилиту lswitch, которая автоматически транслитерирует введенный вами текст с неправильной раскладкой клавиатуры. Больше никаких неприятных моментов, когда случайно забываешь сменить раскладку и печатаешь длинное предложение неправильно.

# ✨ Чем полезна эта утилита?

- Быстро исправляет случайные ошибки ввода.
- Экономит ваше время на повторное переписывание длинных фрагментов текста.
- Легко интегрируется в рабочий процесс через стандартный ввод-вывод (stdin → stdout).

# 🦸 Как работает?
Вы можете столкнуться с ситуацией, когда набираете текст, используя одну раскладку, думая, что активирована другая. Например, вы хотели набрать русские буквы, но компьютер воспринял ваши нажатия как английские символы. Утилита мгновенно преобразует ваш неверно набранный текст в правильный формат, избавляя вас от лишней работы.

# 📋 Основные возможности 🚀
- ~~Автоматическое определение направления перевода (русская ↔ английская раскладка).~~

- Специальные правила кастомизации символов (custom_map), позволяющие настроить индивидуальное поведение преобразования отдельных знаков.
- Быстрая интеграция в пайпы Unix-подобных ОС благодаря стандартному выводу результатов (stdout).

# 🔥 Настройка и использование
Стандартная работа (английский → русский):
```
echo "Yfcrf hfcrwf" | ./bin/lswitch
```
Результат: выводит правильное слово на русском языке ("Привет друг").

Перевод с русского на английский (нужно задать направление через конфиг):
Для ручного изменения направления раскладки создайте файл конфигурации (например, lswitch.yaml) с таким содержанием:
```
direction: "ru2en"
custom_map:
        "@": "#"
```

Затем выполните команду с указанием пути к конфиг-файлу:

```
echo "Дрдг бютвш" | ./bin/lswitch -config configs/ru2en.example.yaml
```
Результатом будет верный английский вариант исходного текста.
